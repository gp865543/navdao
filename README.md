# 🧭 毛玻璃导航

> 一套纯前端、毛玻璃风格的导航站，可免费部署到 **Cloudflare Pages**。
> 支持 **云存储（KV）**，数据跨设备同步不丢失！

## ✨ 特性

- 🪟 **毛玻璃 UI** — `backdrop-filter: blur()` 毛玻璃效果 + 动态渐变背景
- ⚡ **纯前端** — 无需 PHP、MySQL、Node.js 服务端
- 👥 **公共 + 个人双模式**
  - 🌐 **未登录用户** → 看到管理员维护的**公共导航**
  - 🔐 **登录用户** → 看到自己的**个人导航**
- ☁️ **云端存储** — 部署后数据存 Cloudflare KV，换电脑不丢失
- 📦 **JSON 配置** — 修改 `js/data.js` 即可增删链接
- 🔍 **实时搜索** — 按名称/描述快速筛选站点
- 📥 **浏览器收藏夹导入** — 一键导入 Chrome/Edge/Firefox 书签
- 🎨 **自定义背景** — 渐变色 / 图片 / 上传图片
- 🕐 **实时时钟** — 页面顶部显示
- 📱 **响应式** — PC / 平板 / 手机自适应

## 🚀 部署到 Cloudflare Pages（推荐）

### 方式一：一键部署（最简单）

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com)
2. 左侧菜单 → **Workers 和 Pages** → **Pages**
3. 点击 **创建** → **Pages** → **直接上传**
4. 项目名称填 `nav`（或你喜欢的名字）
5. 把本文件夹拖拽上传 → 点击 **部署**
6. 访问 `xxx.pages.dev` 即可使用

> ⚠️ 注意：直接上传方式 **不支持 KV 云存储**，数据存在浏览器本地。

### 方式二：完整部署（支持云端存储 ✅）

#### 第一步：创建 KV 命名空间

1. Cloudflare Dashboard → **Workers 和 Pages** → **KV**
2. 点击 **创建命名空间**，名称填 `NAV_NAV`（随意）
3. 创建后记下该 KV 的 **ID**

#### 第二步：创建 Pages 项目

1. **Workers 和 Pages** → **Pages** → **创建** → **直接上传**
2. 项目名称填 `nav`，上传本文件夹
3. 部署完成后，进入项目 → **设置** → **函数** → **KV 命名空间绑定**
4. 点击 **添加绑定**：
   - 变量名称：`NAV_KV`
   - KV 命名空间：选择刚创建的 `NAV_NAV`
5. 保存后，重新部署一次即可

#### 第三步：验证云存储

- 访问 `你的域名/admin.html`
- 左上角出现 **☁️** 图标说明云存储已启用
- 数据会自动保存到 Cloudflare KV

> 云存储启用后，无论换电脑、清缓存，登录即可恢复数据！

### 方式三：Git 集成（推荐正式使用）

```bash
# 1. 初始化 Git
git init
git add .
git commit -m "初始化毛玻璃导航"

# 2. 推送到 GitHub/GitLab

# 4. 构建设置：框架预设选「无」
# 5. 部署后同样需要绑定 KV 命名空间（同上）
```


## 📖 使用指南

### 公共导航（无需登录）
- 访问首页 → **立即看到公共导航**
- 公共导航由管理员维护，所有未登录用户共享
- 点击右上角 **「登录个人导航」** → 进入自己的空间

### 创建个人账号
1. 在首页点击「登录个人导航」
2. 输入用户名 + 密码（新用户自动创建）
3. 登录后看到自己的导航，可自行增删链接

### 后台管理
访问 `/admin.html`，管理员密码默认为 `admin`：

| 功能 | 说明 |
|------|------|
| 🌐 **公共导航** | 编辑所有未登录用户看到的导航内容 |
| 👥 **用户管理** | 查看/删除注册用户，批量操作 |
| 🎨 **背景设置** | 渐变/纯色/图片背景 |
| 🔑 **修改密码** | 修改管理员密码 |

### 修改导航内容
编辑 `js/data.js` 或 使用后台管理页面：

```js
{
  name: '分类名称',
  icon: '🔍',
  links: [
    { title: '站点名', url: 'https://...', desc: '简介', icon: 'https://...' }
  ]
}
```

### 导入浏览器书签
1. Chrome→书签管理器→导出书签（得到 HTML 文件）
2. 后台 → **导入收藏夹** → 上传文件

### 更换背景
后台 → **背景** → 选择预设/上传图片/输入URL

## 📁 项目结构

```
cloudflare-nav/
├── index.html         # 🏠 前台首页
├── admin.html         # ⚙️ 后台管理
├── _headers           # Cloudflare 安全配置
├── _worker.js         # 🌩️ 云存储 Worker（处理 API + 静态文件）
├── wrangler.toml      # Cloudflare 配置
├── README.md          # 本文件
├── css/style.css      # 样式
└── js/
    ├── data.js        # 数据配置 + 多用户 API + 云存储通信
    ├── app.js         # 前台渲染逻辑
    └── admin.js       # 管理员后台逻辑（独立文件，避免 Cloudflare Minify 破坏）
```

## 🎨 自定义主题

在 `css/style.css` 中调整：
- 毛玻璃透明度：`rgba(255, 255, 255, 0.06)` 中的 0.06
- 模糊强度：`backdrop-filter: blur(20px)` 中的 20px
- 卡片圆角：`border-radius: 14px`
- 背景动画速度：`animation: gradientShift 15s ease infinite`
